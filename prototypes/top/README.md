- 実体：`index.html`（単一HTML・CSS内包・レスポンシブ）
- **現行トップの実構成・実原稿を完全踏襲**（STUDIO公開データから抽出。詳細と改善提案は
  `docs/top-redesign-proposal.md` 参照）
- 検証：PC(1280)/SP(390)レンダリング確認・横スクロールなし・画像パスOK（2026-07-12）

## 構成（現行トップと同一の8セクション）
1. ファーストビュー「地域に何ができるのか、それが全ての発想の原点である」
2. COMPANY 企業情報「地域の未来を創造する」＋理念文＋会社概要をみる
3. BUSINESS 事業内容（4事業軸の説明文）＋事業内容をみる ※6事業リンクチップは追加提案
4. WORKS 実績紹介（CMSカード3件）＋実績紹介をみる
5. NEWS お知らせ（CMSリスト3件）＋一覧をみる
6. CAREER 採用（スタット3点：有給消化率70%以上／資格取得費用補助／4年連続健康経営優良法人認定）＋採用情報について（外部）
7. ACCESS（住所〒027-0052 岩手県宮古市宮町1-3-5＋地図プレースホルダ）
8. 不動産バナー（外部不動産情報サイトへ）

ヘッダー／フッターのリンク構成も現行踏襲（会議室予約=/hole-3 を含む）。

## デザイン上の主な改善（詳細は docs/top-redesign-proposal.md）
- 英文＋和文のセクション見出しの型を全セクションで統一（Lato×オレンジ＋イエロー罫）
- CAREER実績のスタットバッジ化、WORKSの写真カード化、NEWSの行リスト化
- ホバー・スクロール出現などのマイクロインタラクション（STUDIOのアピアランスで再現可）
- 初回のみのローディング（ロゴフェード＋ブランドカラーリング）を継続

## ローディング（初回アクセス時のみ）
- 白背景にロゴをフェードイン＋ブランドカラーの回転リング → 読み込み完了でフェードアウト。
- 同一セッションでは2回目以降スキップ（`sessionStorage`）。最低表示1.1秒・6秒フェイルセーフ。
- `prefers-reduced-motion` に配慮。

## STUDIO再現時の差し替えメモ
- WORKS／NEWS はダミー → STUDIOのCMS（case／news）最新3件に。
- 採用情報・不動産情報の外部リンクは `#` → 実URLに差し替え。
- ACCESSの地図プレースホルダ → Googleマップ埋め込みiframeに。
- COMPANY・CAREERの写真は見本では「葉月の宮古市」の絵画を流用 → 実写写真に差し替え可。
- フォント：見本は Noto Sans JP＋Lato。STUDIO側では現行トークン（新ゴ含む）をそのまま利用可。
- ヘッダーの「お問い合わせ」CTAボタンは追加提案（現行には無し。不要なら削除）。
