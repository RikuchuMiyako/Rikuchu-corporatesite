# トップページ プロトタイプ（見本）

陸中建設株式会社コーポレートサイト（https://rikuchu.co.jp/ ）**トップページのデザイン案**。
運用方針A：この見本を元に及川さんが **STUDIO 上で再現・公開** する（HTML直反映はしない）。

- 実体：`index.html`（単一HTML・CSS内包・レスポンシブ／JSはハンバーガー開閉のみ）
- ローカルでブラウザ表示して確認できます（PC/スマホともに崩れなし・画像パス検証済み 2026-07-11）

## デザインの根拠
- **ブランドカラー**（`docs/brand-guide.md` 確定値）を CSS変数で一元管理
  オレンジ `#F08200`／ブルー `#0097E0`／イエロー `#FFE67A`／補助グレー `#666464`
- **フォント**：`Inter, "Noto Sans JP", sans-serif`（brand-guide 準拠）
- **ヒーロー画像**：`assets/brand/葉月の宮古市_着彩_rgb02_200701.jpg`（宮古市の街並みの絵画）
- **ロゴ**：ヘッダー＝`01光沢ロゴ_社名入り_RGB.png`／フッター（濃色背景）＝`06マットロゴ_社名抜き_RGB.png`
- **キーメッセージ**：「願いを築く」（brand-guide／現サイト description 準拠）

## ローディング（初回アクセス時のみ）
- 白背景にロゴをフェードイン＋ブランドカラー（オレンジ／ブルー）の回転リング → 読み込み完了でフェードアウト。
- **同一セッションでは2回目以降スキップ**（`sessionStorage`）。最低表示1.1秒でチラつき防止、6秒でフェイルセーフ解除。
- `prefers-reduced-motion` に配慮（動きを抑制）。
- STUDIO再現メモ：STUDIOの「ローディング／ページ遷移」機能で **中央ロゴ＋フェード** を再現すればほぼ同等になる。
  回転リングまで作り込めない場合は、ロゴのフェードのみでも可（トンマナは保てる）。

## セクション構成（上から）
1. ヘッダー（sticky・スマホはハンバーガー）
2. ヒーロー「願いを、築く。」＋CTA（事業を見る／採用情報）
3. 理念帯「地域とともに、未来をかたちに。」
4. 事業内容カード6件（建築／土木／砕石／不動産／産業廃棄物／その他）
5. 施工実績プレビュー3件
6. 採用CTA帯
7. お知らせプレビュー3件
8. 会社概要サマリー＋お問い合わせCTA（濃色）
9. フッター

## STUDIO再現時の差し替えメモ
- **お知らせ／施工実績**はダミー。STUDIOのCMS（`news`／`case`）の最新3件に差し替える。
- **施工実績のPHOTO枠**・お知らせ本文は実データに置換。
- **採用CTAのリンク**は暫定で `/contact`。採用専用ページ新設時にそのURLへ差し替え、ヘッダーナビにも「採用」を追加する
  （※`/hole-3` は貸会議室予約ページであり採用ページではない）。
- **会社概要の数値**（資本金・売上・従業員数など）は未確認のためトップには断定表示していない。
  確定後は会社情報ページ（`/company`）側に集約する方針。
- 事業リンク先URLは `docs/site-structure.md` 準拠（不動産は制作中本体 `/business/realestate-1`）。
